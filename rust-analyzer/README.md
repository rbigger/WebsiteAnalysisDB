# SiteScanner Rust Analyzer

High-performance data processing components for large-scale analysis.

## Features

- Fast file system scanning
- Parallel resource processing
- Memory-efficient algorithms
- Native SQLite integration

## Setup

```bash
cd rust-analyzer
cargo build --release
```

## Usage

```bash
cargo run -- --db /path/to/database.db
```

## Testing

```bash
cargo test
```

## Benchmarks

```bash
cargo bench
```
